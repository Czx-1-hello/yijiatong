## Outcome

P3 integrates a bounded RuoYi-Vue-Plus modular monolith and its matching Vue administration UI. It reuses mature authentication, Sa-Token authorization, RBAC, menu routing, system management, login audit, operation audit, and health infrastructure without adding product-domain behavior.

## Included and excluded scope

Included backend capabilities are `ruoyi-admin`, `ruoyi-api`, shared common modules needed by the runtime, and `ruoyi-system`. Included UI capabilities are login, system management, monitoring, RBAC-driven navigation, and audit views.

AI, demo, code generator, scheduler, workflow, extension applications, and their UI views are excluded. P3 contains no product table, product CRUD, `UnifiedProductOffer`, platform Adapter, real platform API, or Mini Program UI change.

## Security and configuration

- Database, Redis, JWT, administrator bootstrap, Actuator, origin, and API encryption settings cross the process environment boundary.
- `.env.example` contains names and non-production placeholders only. Ignored `.env` files are never read by repository checks.
- The seed administrator is disabled. It can be activated only by an explicit bootstrap switch and valid process credentials.
- Bootstrap username/password validation matches the upstream login contract; passwords must contain 12-30 characters.
- Actuator remains protected by Basic Auth with no repository default.
- Production configuration has no database, Redis, JWT, Actuator, or administrator credential fallback.
