## Current data-flow conclusion

The actual path is:

```text
Page lifecycle/event
  -> services/<domain> exported function
  -> config.useMock === true
  -> services/_utils/delay (normally 200 ms)
  -> model/<domain> generator/filter
  -> fixed local objects, generated response metadata, and Tencent CDN image URLs
  -> Promise result returned to the page
```

No active `wx.request` call exists. The only `wx.requestPayment` occurrence is commented out. When `config.useMock` is false, service functions return the placeholder string `real api`; therefore the non-mock path is not runnable.

See [mock-data-flow.md](evidence/P0/mock-data-flow.md) for the page-to-service-to-model map.
